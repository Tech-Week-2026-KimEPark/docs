# 협업 규칙

팀 4명의 진행 상황 공유, 의사 결정, AI 사용, 대회 당일 운영 규칙입니다. 원본은 [전체 묶음 요약본](../sar-전체-묶음.md) 5부의 협업 규칙입니다.

## 진행 상황 공유

| 상황 | 규칙 |
|---|---|
| 작업 시작 | 팀 채널에 브랜치 이름과 예상 완료 시각 공유 |
| 15분 지연 | 팀 채널에 `[담당자] 증상 / 시도한 조치 / 필요 사항` 형식으로 공유 |
| 30분 지연 | A가 대안 결정([플레이북 11장](../../how-to/sar-형식별-전략-플레이북.md)), 추가 조사 중단 |
| 인터페이스 변경 | 코드 수정 전에 사용하는 모듈 담당자에게 공유. [모듈 인터페이스](https://github.com/Tech-Week-2026-KimEPark/sar-robot/blob/main/docs/human/reference/interfaces.md)를 같은 PR에서 갱신 |
| 문제 해결 | 관련 담당자 2명이 별도로 진행. 전체 회의로 확대하지 않음 |

## 의사 결정 권한

| 결정 대상 | 결정자 |
|---|---|
| 모듈 내부 구현, 알고리즘 선택 | 해당 모듈 담당자 |
| 작업 우선순위, 스코프 축소 | A |
| 모듈 인터페이스 | 제공 모듈 담당자와 사용 모듈 담당자 합의. 5분 안에 합의하지 못하면 A |
| 대회 규정 해석 | A. 불명확하면 주최측에 질문 |

의견이 5분 이상 합의되지 않으면 위 표의 결정자가 결정합니다.

## AI 사용 규칙

| 항목 | 규칙 |
|---|---|
| 계정 배분 | Claude 1은 A(통합·리뷰), Claude 2는 B(알고리즘), GPT는 C(인식·디버깅). D는 Claude 1·GPT 공유 |
| 사용 한도 도달 | 백업 짝 계정으로 전환(A↔B, C↔D) |
| 대화 시작 | 새 대화에 `CONTEXT.md`와 작업 대상 파일만 첨부 |
| 저장소 규칙 | AI 코딩 도구는 sar-robot의 `AGENTS.md`를 읽고 작업함 |
| 브랜치·커밋 | AI 도구 이름과 서명을 넣지 않음 |

`CONTEXT.md`는 대회 시작 후 A가 sar-robot 루트에 작성합니다. 대회 형식(S1~S6), 채점 기준, 장치 이름, 좌표축, 금지 사항을 적으십시오. 대회 0:15 체크포인트에서 확정합니다.

AI가 작성한 코드는 머지 전에 다음 항목을 확인하십시오. 같은 항목이 PR 템플릿에 있습니다.

- 단독 테스트 통과
- x/y와 row/col 혼동 없음
- 도와 라디안 혼용 없음, 회전 부호 확인
- `while` 루프 타임아웃 존재
- `None`을 받았을 때 예외 없이 처리
- 매직 넘버를 `config.py`로 분리

## 대회 당일 운영

체크포인트와 180분 시간표는 [전체 묶음 요약본](../sar-전체-묶음.md) 5부 4장을 따르십시오. 다음 시각은 일정이 지연되어도 변경하지 않습니다.

| 시각 | 항목 |
|---|---|
| 0:15 | 대회 형식 확정, `CONTEXT.md` 확정 |
| 1:00 | 최소 구현으로 1회 완주 |
| 1:15 | 완주 시 태그 `v1`, 미완주 시 스코프 축소 |
| 2:15 | 기능 동결, 태그 `v2` |
| 2:40 | 데모 영상 확보 |

체크포인트는 A가 진행합니다. 각자 완료 항목, 문제 항목, 다음 30분 작업을 1줄씩 보고하십시오.
