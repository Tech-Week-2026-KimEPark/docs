# 기능 문서

sar-robot에서 구현한 기능별 동작과 검증 결과를 설명하는 문서입니다. 기능 1개를 구현하면 구현한 사람이나 AI가 같은 작업에서 이 폴더에 문서를 작성합니다. 파일 구조와 함수 형식의 원본은 [과제와 구현 기준](../../reference/sar-과제-구현-기준.md) 7장입니다.

## 작성 대상

다음 변경은 기능 구현으로 보고 기능 문서를 작성하십시오.

| 변경 | 예 |
|---|---|
| `controllers/sar_main/sar/`에 모듈 추가 | `grid_map.py`, `mission.py` |
| 공개 함수·클래스 추가 | `TargetDetector.detect_all()` |
| 기존 공개 함수의 동작 변경 | 경로 추종 목표점 선택 방식 변경 |
| 컨트롤러 추가 | `controllers/hsv_tuner/` |

오타 수정, 주석·형식 변경, 테스트만 추가한 변경은 대상이 아닙니다.

## 작성 기준

| 항목 | 기준 |
|---|---|
| 작성 시점 | 기능 구현 PR과 같은 작업 |
| 파일 이름 | `<모듈 이름>.md`. 기능이 여러 모듈에 걸치면 주 모듈 이름 사용 |
| 갱신 | 같은 모듈 문서가 있으면 새 파일 대신 기존 문서 갱신 |
| 검증 결과 | 실행한 명령과 결과만 기재. 실행하지 않은 항목은 "미확인"으로 구분 |
| 수식 | LaTeX 표기 ([문서 작성 안내](../../how-to/write-docs.md) 수식 표기 절) |
| 저장소 작업 | docs 저장소의 `docs/<모듈 이름>-feature` 브랜치와 PR. sar-robot PR 본문에 docs PR 링크 기재 |

문서를 추가하면 이 파일의 목록에 한 줄을 추가하고 docs 저장소에서 다음 명령을 실행하십시오.

```bash
python3 scripts/check_docs.py --write-catalog
python3 scripts/check_docs.py --workspace
```

## 문서 구성

```markdown
# <모듈 이름> 기능 설명

이 문서는 sar-robot `<파일 경로>`에 구현한 <기능>의 동작과 검증 결과를 설명합니다.

## 과제와의 관계

- 담당하는 과제 요구사항과 상태 머신 단계

## 동작 원리

- 처리 순서, 계산식, 선택한 방법과 이유

## 인터페이스와 설정값

| 함수 | 입력 | 출력 |
|---|---|---|

| 설정값 | 값 | 의미 |
|---|---|---|

## 검증 결과

| 항목 | 명령·조건 | 결과 |
|---|---|---|

## 한계와 확인 필요 항목

- 알려진 제약, 미확인 동작, 후속 작업

## 관련 자료

- 구현 PR, 원본 인터페이스 절, 관련 기능 문서
```
