# viz 기능 설명

이 문서는 sar-robot `controllers/sar_main/sar/viz.py`에 구현한 지도 시각화 그림 생성과 저장의 동작과 검증 결과를 설명합니다.

## 과제와의 관계

- 대회 공지의 권장 사항인 지도 시각화를 담당함
- 상태 머신의 RESCUE와 DONE 단계, `MAP_SAVE_PERIOD` 주기에 지도 이미지를 저장하는 데 사용함. 호출은 `mission` 담당
- 저장한 그림은 시연 영상, README 결과 확인 절, 발표 자료의 증빙 자료임

## 동작 원리

`render_map()`은 다음 순서로 그림을 생성합니다.

1. 공개값 격자(−1 모름, 0 빈칸, 1 장애물)에서 확인된 칸의 범위를 구하고 `MAP_VIEW_MARGIN`칸 여백을 더해 자름
2. 칸 값을 회색, 흰색, 검은색으로 칠하고 상하를 뒤집음. 격자 row 0이 y 최소이므로 뒤집으면 +y가 그림 위쪽이 됨
3. `MAP_VIEW_SCALE`배로 확대함
4. 주행 궤적, 계획 경로, 시작점, 구조 위치, 현재 로봇 위치를 그림
5. 제목과 구조 목록(순서, 위치, 시각)을 그림 위쪽 머리 영역에 표시함

| 표시 대상 | 모양 | 색 |
|---|---|---|
| 모르는 칸, 빈칸, 장애물 | 칸 채우기 | 회색, 흰색, 검은색 |
| 주행 궤적 | 선 1 px | 파랑 |
| 계획 경로 | 선 2 px | 초록 |
| 시작점 | 사각형 | 보라 |
| 구조 위치 | 채운 원과 구조 순서 번호 | 빨강 |
| 현재 로봇 위치 | 원 | 주황 |

월드 좌표를 격자 칸으로 바꾸는 함수는 호출하는 쪽에서 `to_cell`로 전달합니다. `viz`는 `grid_map`의 격자 원점과 해상도를 알 필요가 없습니다. 외부 패키지는 OpenCV와 numpy만 사용합니다. 저장에 실패하면 예외 대신 `False`를 반환하므로 미션 루프가 멈추지 않습니다.

## 인터페이스와 설정값

| 함수 | 입력 | 출력 |
|---|---|---|
| `render_map(grid, to_cell, trajectory, path, rescued, start, pose, title, margin, scale)` | 공개값 격자, 월드→격자 변환 함수, 월드 좌표 목록. `rescued`는 `(x, y, t)` 목록 | BGR `uint8` 그림 |
| `save_map(path, image)` | 저장 경로, 그림 | 저장 성공 여부. 폴더가 없으면 생성 |

| 설정값 | 값 | 의미 |
|---|---|---|
| `MAP_SAVE_DIR` | `"output"` | 지도 이미지 저장 폴더. 컨트롤러 폴더 기준 |
| `MAP_SAVE_PERIOD` | 5.0 | 주기 저장 간격 [s]. 미션에서 적용 |
| `MAP_VIEW_MARGIN` | 20 | 확인된 영역 바깥 여백 [칸] |
| `MAP_VIEW_SCALE` | 2 | 격자 1칸의 픽셀 수 |

## 검증 결과

2026-09-30 sar-robot `feat/tuner-auto-measure` 브랜치에서 확인했습니다.

| 항목 | 명령·조건 | 결과 |
|---|---|---|
| 단위 테스트 | `python -m pytest -q tests/test_viz.py` | 6개 통과 |
| 자르기·상하 반전 | 테스트: 20 × 20칸 방, 여백 0 | 그림 20 × 20 px, y 최소 벽이 맨 아래 줄 |
| 빈 격자 | 테스트: 전체가 모르는 칸 | 격자 전체를 그림 |
| 저장 실패 | 테스트: 파일 아래 경로에 저장 | `False` 반환 |
| 단독 실행 | `controllers/sar_main`에서 `python -m sar.viz` | `output/viz_demo.png` 저장. 궤적, 경로, 시작점, 구조 번호, 로봇 위치가 좌표와 같은 방향에 표시됨을 그림으로 확인 |
| 실제 지도 렌더링 | `grid_map` 출력 격자 | 미확인. `grid_map` 미구현 |

## 한계와 확인 필요 항목

- `grid_map` 공개 인터페이스 `layers()`는 불리언 배열 여러 장을 반환함. `render_map()`에 넘길 공개값 격자(−1, 0, 1) 변환 위치를 계획 담당과 정해야 함
- 640 × 640칸 격자를 전부 확인한 경우 그림은 약 1280 × 1280 px임. 저장 시간은 미확인
- 로봇 방향은 표시하지 않음
