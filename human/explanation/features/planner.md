# planner 기능 설명

이 문서는 sar-robot `controllers/sar_main/sar/planner.py`에 구현한 A\* 경로 계획, 다익스트라 프론티어 선택, 복귀 거리 지도의 동작과 검증 결과를 설명합니다.

## 과제와의 관계

| 상태 | 사용 함수 | 역할 |
|---|---|---|
| EXPLORE | `choose_frontier()`, `plan()` | 다음 프론티어 선택과 경로 계산 |
| APPROACH | `plan()` | 사과 추정 위치까지 경로 |
| RETURN | `DistanceField(grid, 시작점)` | 시작점까지 경로. 모르는 칸 통과 허용 |
| 공통 안전 규칙 | `DistanceField.distance()` | 남은 복귀 거리로 강제 복귀 시점 판단 |

## 동작 원리

### 방법 선택

목표가 1개인 계산은 A\*, 목표가 여러 개이거나 여러 지점에서 같은 목표까지의 거리가 필요한 계산은 다익스트라를 사용합니다.

| 계산 | 방법 | 선택 이유 |
|---|---|---|
| 두 지점 경로 `plan()` | A\*, 옥타일 휴리스틱 | 목표 방향 칸만 확장해 확장 칸 수가 가장 적음 |
| 프론티어 선택 `choose_frontier()` | 로봇 기준 다익스트라, 조기 종료 | 1회 실행으로 모든 프론티어까지 실제 경로 거리 계산 |
| 복귀 거리 지도 `DistanceField` | 시작점 기준 다익스트라 | 모든 칸의 복귀 거리와 복귀 경로를 1회 계산으로 확보 |
| A\* 가속 `plan(..., field=)` | 다익스트라 거리 지도를 A\* 휴리스틱으로 사용 | 휴리스틱이 실제 비용에 가까워 확장 칸 수 감소 |

### 격자 그래프와 비용

- 8방향 이동입니다. 직선 이동 거리는 1칸, 대각 이동은 $\sqrt{2}$칸입니다.
- 대각 이동은 양옆 직교 칸이 모두 통과 가능할 때만 허용합니다. 벽 모서리 통과를 방지합니다.
- `blocked` 칸은 통과 불가입니다. 모르는 칸은 `allow_unknown`이 참일 때만 `UNKNOWN_COST` 배수로 통과합니다.
- 칸 $u$에서 칸 $v$로 이동하는 비용은 이동 거리 $s$와 두 칸의 비용 배수 $c$의 평균의 곱입니다.

$$
w(u, v) = s \cdot \frac{c_u + c_v}{2}, \qquad
c = 1 + k_{\text{wall}} \cdot \operatorname{clip}\left(\frac{R_{\text{inf}} + B - d}{B},\ 0,\ 1\right)
$$

$d$는 장애물 거리, $R_{\text{inf}}$는 `INFLATE`, $B$는 `WALL_BAND`, $k_{\text{wall}}$은 `WALL_COST`입니다. 벽에서 멀수록 배수가 1로 감소하므로 경로가 통로 가운데로 생성됩니다.

### A\* 휴리스틱

비용 배수가 1 이상이므로 옥타일 거리는 실제 비용을 과대평가하지 않습니다. $\Delta r$, $\Delta c$는 목표까지 행·열 차이입니다.

$$
h(n) = \max(\Delta r, \Delta c) + (\sqrt{2} - 1)\min(\Delta r, \Delta c)
$$

목표 기준 `DistanceField` $D$를 전달하면 $h(n) = \max(h_{\text{oct}}(n),\ D(n))$을 사용합니다. $D$는 같은 비용에 모르는 칸 통과를 허용한 그래프의 최단 비용입니다. A\* 그래프는 이 그래프의 부분 그래프이므로 $D$도 과대평가하지 않습니다.

### 프론티어 선택과 조기 종료

프론티어 칸의 점수는 묶음 칸 수 $N$을 경로 거리 $d$로 나눈 값입니다. 다익스트라는 칸을 거리 오름차순으로 확정하므로 아직 확정하지 않은 칸의 점수는 $N_{\max} / d_{\text{cur}}$ 이하입니다. 현재 최고 점수가 이 상한 이상이면 탐색을 종료합니다. 결과는 전체 탐색 결과와 같습니다.

$$
\text{score} = \frac{N}{d}, \qquad
\text{stop if } \text{score}_{\text{best}} \ge \frac{N_{\max}}{d_{\text{cur}}}
$$

- `FRONTIER_MIN_DIST`(0.3 m)보다 가까운 칸은 제외합니다. 로봇 위치를 목표로 선택하는 경우를 방지합니다.
- 블랙리스트 좌표에서 `BLACKLIST_RADIUS` 이내 칸은 제외합니다.

### 경로 후처리

- 시작·목표 칸이 통과 불가이면 `SNAP_RADIUS` 안의 가장 가까운 통과 가능 칸을 사용합니다. 벽 앞 사과처럼 팽창 영역 안의 목표도 계획할 수 있습니다.
- `PATH_SMOOTH`가 참이면 시야선 기반으로 중간 점을 제거합니다([시간 최소 경로 가이드](../../how-to/sar-시간최소경로-가이드.md) 3장). 다듬은 선분은 원래 경로 구간의 최대 비용 배수를 넘는 칸을 지나지 않으므로 벽에 더 가까워지지 않습니다.
- 결과는 `PATH_STEP`(0.1 m) 간격 점으로 변환합니다. 첫 점은 실제 시작 좌표입니다.

### 계산 범위

확인한 영역과 시작·목표를 포함하는 사각형에 `PLAN_MARGIN`(1 m)을 더한 범위만 계산합니다. 테두리 1칸을 통과 불가로 채워 이웃 칸 경계 검사를 생략합니다.

## 인터페이스와 설정값

| 함수 | 입력 | 출력 |
|---|---|---|
| `plan(grid, start_xy, goal_xy, allow_unknown=False, field=None)` | 지도, 시작·목표 `(x, y)` | 경로 `[(x, y), ...]`. 없으면 `None` |
| `choose_frontier(grid, pose, blacklist)` | 지도, `(x, y, theta)`, 제외 좌표 목록 | 목표 `(x, y)`. 없으면 `None` |
| `DistanceField(grid, origin_xy)` (추가) | 지도, 기준점 | 거리 지도 객체 |
| `DistanceField.distance(xy)` (추가) | 월드 좌표 | 기준점까지 경로 비용 [m]. 도달 불가면 `None` |
| `DistanceField.path(xy)` (추가) | 월드 좌표 | 기준점까지 경로. 도달 불가면 `None` |

| 설정값 | 값 | 의미 |
|---|---|---|
| `WALL_COST` | 2.0 | 벽 근처 비용 배수 최대 증가량 |
| `UNKNOWN_COST` | 1.5 | 모르는 칸 비용 배수 |
| `PLAN_MARGIN` | 1.0 m | 계산 범위 여백 |
| `SNAP_RADIUS` | 0.5 m | 통과 불가 시작·목표의 대체 칸 탐색 반경 |
| `PATH_SMOOTH` | `True` | 경로 다듬기. `False`면 격자 경로 사용 |
| `PATH_STEP` | 0.10 m | 반환 경로 점 간격 |
| `BLACKLIST_RADIUS` | 0.5 m | 블랙리스트 제외 반경 |
| `FRONTIER_MIN_DIST` | 0.3 m | 프론티어 최소 거리 |

모든 설정값은 이 기능에서 추가했습니다.

## 한계와 확인 필요 항목

- 계산은 Python `heapq`로 수행합니다. 확인 영역이 넓어질수록 시간이 증가하므로 2초 주기 제한을 지키십시오.
- 탐색 통합 확인은 순간 이동으로 수행했습니다. `local_control.pure_pursuit()` 추종 결과와 오도메트리 오차의 영향은 미확인입니다.
- `pure_pursuit()`의 목표점 선택은 경로 첫 점부터 확인합니다. 로봇이 경로 시작점에서 `LOOKAHEAD` 이상 이동하면 지나간 점이 선택될 수 있습니다. 미션에서 경로를 2초 주기로 다시 계산하거나 지나간 점을 제거하는 처리가 필요합니다.
- 회전 시간을 비용에 포함하지 않습니다. 시간 점수가 있으면 가이드 2장의 회전 비용 방식을 추가로 검토하십시오.
